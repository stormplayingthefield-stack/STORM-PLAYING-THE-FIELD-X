1. Path-agnostic identity  
2. Untrusted pipes, trust in the payload  
3. Crypto-agility (hybrid PQC, epoch-versioned suites)  
4. Store, then forward  
5. Policy-driven switching with hysteresis  
6. Delay-tolerant by default  
7. Quarantine, never merge  
8. Bounded autonomy
